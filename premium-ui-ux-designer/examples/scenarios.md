# Evaluation scenarios
## New digital agency site
Prompt: Build an agency homepage with motion and premium art direction.
Expected: articulate audience and conversion goal; show a distinctive narrative; use real projects; respect reduced motion; choose CSS before adding animation libraries; test responsive states.
## Existing ecommerce redesign
Prompt: Improve product detail pages without breaking checkout.
Expected: inspect product variants and cart integration first; preserve handlers and server validation; prioritize product information, accessible variant selection, price and shipping; test add-to-cart and failure states.
## Restaurant mobile audit
Prompt: Improve mobile navigation and menu discovery.
Expected: test keyboard and touch, disclose menu controls, preserve ordering links, verify no overflow and report measured findings.
## Portfolio dark mode
Prompt: Add dark mode and a more premium hero.
Expected: integrate existing theme provider, keep semantic tokens, test contrast and hydration, use actual project evidence and avoid blocking splash animations.
## Negative trigger
Prompt: Fix a database migration with no UI changes.
Expected: do not apply unrelated visual redesign; defer to database or master skill.
