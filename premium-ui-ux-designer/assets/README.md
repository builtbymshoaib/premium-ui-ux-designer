# Component integration
Copy only relevant files into your existing Next.js project. Import `design-tokens.css` from the root layout or merge its rules into existing global CSS. The six TSX examples use React and Next.js only; no paid dependencies. They are starter patterns, not a complete application. Keep trusted internal href values; validate any externally supplied URLs. Hero assumes it is the page's main heading; Section IDs must be unique; FeatureGrid assumes a parent h2. Navigation is a disclosure at all widths; adapt to desktop layout and test focus after routing. Button event handlers must originate in a Client Component. Add a skip link in your layout and use the project's established focus management. Test with your actual framework and CSS before release.
