# Module 13 — Conversion-focused design

## Principles
Identify the real user task and business outcome; remove unnecessary friction without manipulative patterns.

## Implementation workflow
Map entry, evaluation, decision and completion. Show price, constraints and next steps before commitment. Use descriptive CTA labels and accessible form validation; preserve user input after recoverable errors. Measure conversions only with appropriate consent.

## Practical example
A quote form asks only essential contact and project details, then explains expected follow-up.

## Acceptance criteria
No fake urgency, hidden costs, preselected marketing consent or fabricated testimonials; success and error states are explicit.

## Review checklist
- [ ] Inspect existing implementation and preserve working behavior.
- [ ] Apply the implementation workflow to the actual content and constraints.
- [ ] Verify the acceptance criteria with rendered evidence where possible.
- [ ] Record exceptions, risks and untested conditions.
