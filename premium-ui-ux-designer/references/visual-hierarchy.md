# Module 12 — Visual hierarchy & spacing

## Principles
Establish a consistent type scale, spacing scale and visual priority. Use grouping and proximity to communicate relationships rather than borders everywhere.

## Implementation workflow
Define 4/8-based spacing tokens, fluid section spacing and consistent alignment. Use one dominant element per section, secondary supporting copy and tertiary details. Audit density separately for dashboards and marketing pages.

## Practical example
A product page prioritizes name, price, variant choice and purchase action; shipping details remain nearby but visually subordinate.

## Acceptance criteria
Primary actions stand out without relying on color alone; scan order matches document order; unrelated items have greater spacing than related items.
