# Module 09 — Mobile-first responsive design

## Principles
Design for content and input modality rather than specific device brands. Use fluid dimensions and breakpoints only where layout breaks.

## Implementation workflow
Start at 320px, then check 375, 768, 1024, 1440 and 1920px plus landscape and 200% zoom. Use responsive images and grid collapse; avoid fixed heights on text containers. Aim for 44px touch targets, while meeting applicable WCAG minimums.

## Practical example
A three-column service grid becomes two then one column; product filters become a disclosure on narrow screens.

## Acceptance criteria
No clipped text or unreachable controls; primary flows work on touch and keyboard; screenshots recorded at representative widths.

## Review checklist
- [ ] Inspect existing implementation and preserve working behavior.
- [ ] Apply the implementation workflow to the actual content and constraints.
- [ ] Verify the acceptance criteria with rendered evidence where possible.
- [ ] Record exceptions, risks and untested conditions.
