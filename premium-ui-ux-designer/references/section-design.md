# Module 07 — Professional section design

## Principles
Build a narrative: offer, evidence, relevant benefits, details, objections and next step. Do not blindly add every common section.

## Implementation workflow
Choose sections according to the business goal. Use alternating visual rhythms and one consistent content width. Include loading, empty and error states for dynamic sections. Keep real claims traceable; omit fake reviews and counters.

## Practical example
For B2B textiles: hero, product categories, sector applications, quality evidence, bulk ordering process and quote CTA.

## Acceptance criteria
Every section has a distinct purpose; repeated CTA destinations are consistent; no placeholder claims reach production.

## Review checklist
- [ ] Inspect existing implementation and preserve working behavior.
- [ ] Apply the implementation workflow to the actual content and constraints.
- [ ] Verify the acceptance criteria with rendered evidence where possible.
- [ ] Record exceptions, risks and untested conditions.
