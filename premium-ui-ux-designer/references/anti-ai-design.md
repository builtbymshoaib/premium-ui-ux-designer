# Module 16 — Anti-generic AI design rules

## Principles
Avoid formulaic repeated card grids, decorative gradients, excessive pills, identical section compositions, meaningless badges and empty marketing copy. These are heuristics, not blanket bans.

## Implementation workflow
Create an art-direction sentence, visual references with lawful use, distinct composition choices and content-specific typography. Audit each section for repeated patterns and remove decorations that do not support purpose. Use real project details and unique copy.

## Practical example
Replace a generic icon-card About section with a narrative, relevant image and verifiable evidence; keep cards when comparison genuinely benefits.

## Acceptance criteria
Design decisions can be traced to audience and brand; no copied proprietary designs, invented metrics or gratuitous effects.

## Review checklist
- [ ] Inspect existing implementation and preserve working behavior.
- [ ] Apply the implementation workflow to the actual content and constraints.
- [ ] Verify the acceptance criteria with rendered evidence where possible.
- [ ] Record exceptions, risks and untested conditions.
