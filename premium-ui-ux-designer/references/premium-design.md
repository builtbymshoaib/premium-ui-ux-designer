# Module 01 — Premium & luxury design

## Principles
Define brand attributes, audience, primary task and price positioning before styling. Choose one art direction: editorial luxury, restrained corporate, expressive creative or product-led minimalism. Luxury means intentional restraint, not gold accents everywhere.

## Implementation workflow
Create two materially different concepts when direction is open: one editorial with asymmetric composition and one product-led with strong information hierarchy. Select using audience fit, content availability and implementation cost. Use authentic imagery with documented usage rights.

## Practical example
A luxury hotel uses large landscape photography, quiet typography and a single booking action; a SaaS dashboard instead emphasizes density and legibility.

## Acceptance criteria
The design can be described without mentioning gradients or cards; the first viewport communicates the offer and next action.

## Review checklist
- [ ] Inspect existing implementation and preserve working behavior.
- [ ] Apply the implementation workflow to the actual content and constraints.
- [ ] Verify the acceptance criteria with rendered evidence where possible.
- [ ] Record exceptions, risks and untested conditions.
