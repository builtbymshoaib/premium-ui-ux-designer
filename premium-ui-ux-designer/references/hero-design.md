# Module 05 — Hero section design

## Principles
Explain who the site serves, what it provides and what to do next. Prefer meaningful headings to vague slogans. Use one primary action and an optional genuine secondary action.

## Implementation workflow
Select a split, full-bleed editorial, product-first or typographic hero based on available assets. Keep the LCP asset discoverable, sized and optimized. Never delay access behind an obligatory splash screen.

## Practical example
For a developer portfolio: clear role, concrete specialty, View work and Contact actions, with a project screenshot instead of stock imagery.

## Acceptance criteria
Heading and CTA remain visible and understandable on small screens; image has appropriate alt text or is decorative; no unverified social proof.

## Review checklist
- [ ] Inspect existing implementation and preserve working behavior.
- [ ] Apply the implementation workflow to the actual content and constraints.
- [ ] Verify the acceptance criteria with rendered evidence where possible.
- [ ] Record exceptions, risks and untested conditions.
